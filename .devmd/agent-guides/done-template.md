# Implementation Completion Template

각 slice 작업이 끝나면 해당 slice README 하단에 아래 형식으로 기록한다.

```markdown
## Implementation Completion Placeholder

- Status: [ ] Not Started / [ ] In Progress / [ ] Completed
- Branch:
- Commit / PR:
- Implemented files:
  - 
- Test commands executed:
  - 
- Test result:
  - 
- Known issues:
  - 
- Fallback behavior:
  - 
- Next recommended task:
  - 
```

완료 선언 기준:

1. 해당 slice의 `Required Deliverables`가 모두 존재한다.
2. 해당 slice의 `Test Harness` 명령을 최소 1회 실행했다.
3. 실패 항목이 있으면 원인과 임시 대응을 명시했다.
4. 다음 slice가 작업을 이어받는 데 필요한 interface/API/env 변경을 문서화했다.
